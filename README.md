# Factory-Frenzy-Group2
Platformer with multiplayer and AR/VR features, Developed in Unity

Please refer to the [Project Specs Powerpoint](https://viacesifr-my.sharepoint.com/:p:/g/personal/cedric_hoog_viacesi_fr/IQC0CfOTUsYUSq_DLcXYQhwLAbjxlQ4VuCT3QxU5e1E7pc0?e=DH2tuM) for details about the features

## Structure
- [Platformer](./Platformer/) : Multiplayer Platformer. Loads levels from .json files.
- [VR Level Editor](./VR Level Editor/) : VR Level editor. Create & Save levels to json.
- [Shared Assets](./Shared Assets/) : Contain all shared files & level save files.
